# saSamplesAndTests
## Net48_Parser
This example implements an interpreter for complex mathematical expressions.

### Important NOTE
The decimal number format here is designed for use in German-speaking regions.

### Numeric Operators
```
REB-compliant:
+  addition
-  subtraction
*  multiplication
/  division
** to raise to a power

extended:
^  to raise to a power
```

### Logical operators
```
extended:
|   OR
&   AND
=   equal
<>  not equal
>=  greater or equal
<=  less or equal
>   greater
<   less
```

### Functions
```
REB-compliant:
sin    sine
cos    cosine
tan    tangent
asin   arcsine
acos   arccosine
atan   arctangent

extended:
abs    absolute value
sqrt   square root
sqr    the same as sqrt
qdrt   square
exp    exponential function based on e
log    logarithm based on e
log10  logarithm based on 10
```
